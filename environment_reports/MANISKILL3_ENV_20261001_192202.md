## SAPIEN cache patch

SAPIEN 3.0.3 ignores `MS_ASSET_DIR` for its GPU runtime and hard-codes `Path.home() / ".sapien"`. Applied `patches/sapien-3.0.3-project-cache.patch` to the new environment only. The patch adds `SAPIEN_CACHE_DIR` support while preserving the original fallback. The dependency file was replaced with a new inode to preserve uv's shared cache and other environments. Upstream ManiSkill is unmodified. Reinstalling SAPIEN requires reapplying this patch before enabling GPU simulation.

First smoke attempt was interrupted before rollout while downloading to the default home path; the newly created directories were empty and removed. The initial project-local runtime transfer stalled; HTTP/1.1 continuation uses its existing partial download. Logs preserve both interruptions.
